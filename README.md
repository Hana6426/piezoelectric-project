# Piezoelectric Project

This repository contains input files, scripts, and results for the final project on piezoelectric materials for AP275 / computational materials.

## Structure
- `inputs/` — Quantum ESPRESSO input files for relaxation, phonons, and polarization.
- `scripts/` — Helper scripts to run calculations and parse outputs.
- `results/` — Selected processed results (figures, tables, key output snippets).
- `docs/` — Notes on theory, workflow, and derivations.

## Goals
- Compute relevant properties (e.g. polarization, piezoelectric response) for selected materials.
- Document a clear, reproducible workflow that can be shared with instructors and collaborators.
